## Полезные команды для проверки

```bash
# Проверка Redis
redis-cli ping

# Проверка метрик
curl http://localhost:3000/metrics | grep -E "(redis_health|overlay_connections|poll_)"

# Проверка health
curl http://localhost:3000/health

# PM2 статус
pm2 status

# PM2 логи
pm2 logs --lines 100

# Мониторинг ресурсов
pm2 monit
```
